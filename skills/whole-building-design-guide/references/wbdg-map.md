# Where things live — WBDG and NBIMS-US

Use this to pick good search queries. Site structure changes over time; if a path
404s, search the topic with `allowed_domains: ["wbdg.org", "nibs.org"]`.

## WBDG main areas (wbdg.org)

| Area | What's there | Typical query |
|---|---|---|
| Design Objectives | Accessible, aesthetics, cost-effective, functional, historic preservation, productive, secure/safe, sustainable | "WBDG sustainable design objective" |
| Building Types | Guidance per type (laboratories, courthouses, hospitals, offices…) | "WBDG laboratory building type" |
| Space Types | Guidance per space (data center, clean room, auditorium…) | "WBDG data center space type" |
| Project Management | Delivery methods, commissioning, project planning | "WBDG commissioning" |
| Operations & Maintenance | Facility management, COBie, O&M | "WBDG COBie" |
| Design Disciplines | Architecture, structural, MEP, fire protection, etc. | "WBDG fire protection engineering" |
| Federal Facility Criteria (FFC) | Official agency criteria documents | see below |

## Federal Facility Criteria — who publishes what

| Agency | Key documents | Query |
|---|---|---|
| DoD (all services) | Unified Facilities Criteria (UFC), Unified Facilities Guide Specifications (UFGS) | "UFC 1-300" / "UFGS 01" |
| USACE | Design guides, BIM/CAD requirements, A/E guide; CAD/BIM Technology Center's **A/E/C Graphics Standard** (ERDC/ITL SR-23-1, Release 2.2, 2023) and **A/E/C CAD Standard** (Release 6.1, ERDC/ITL TR-19-7) under wbdg.org/FFC/AECCAD | "A/E/C Graphics Standard" / "A/E/C CAD Standard" / "USACE BIM requirements" |
| NAVFAC | Design-build RFP templates, Navy design procedures | "NAVFAC design procedures BIM" |
| GSA | P100 Facilities Standards plus the annual PBS Core Building Standards memo (both on gsa.gov); BIM Guide series and BIM Technical Standards (spatial program, 3D imaging, minimum attributes, FM) | "GSA P100" / "GSA Core Building Standards" / "GSA BIM technical standards" |
| VA | VA BIM Standards / BIM Guide, design manuals | "VA BIM standard" |
| NASA | Guides and handbooks | "NASA facilities guides handbooks" |
| DHS / FEMA | Building science and resilience publications | "FEMA building science" |

When a project is for one of these agencies, its criteria override generic guidance.
Always tell the user which agency document governs and its version/date.

## NBIMS-US (nibs.org)

| Part | Use it for |
|---|---|
| BIM Execution Plan (BEP) standard | Required BEP contents, terminology (Project BEP vs. Appointment BEP) |
| COBie | Facility handover data format and deliverable requirements |
| Reference standards | IFC, ISO 19650 alignment, NCS |
| Practice documents | Planning guides, including the Penn State BIM Project Execution Planning Guide |

Related: the Penn State BIM Project Execution Planning Guide (v3) and templates are
free under a Creative Commons license at bim.psu.edu.
